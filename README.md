# RASULOV — GRAVITY / DIGITAL SPACE

Статический многостраничный сайт-портфолио. Не требует сборки, Node.js или сторонних библиотек.

## Структура

- `index.html` — главная
- `projects.html` — список проектов
- `case.html?project=saklya` — повторно используемый шаблон кейса
- `about.html` — обо мне
- `contact.html` — контактная страница и копируемый бриф
- `assets/style.css` — дизайн-система и адаптивность
- `assets/app.js` — меню, reveal-анимации, кейсы и копирование брифа

## Проверка локально

Открой `index.html` в браузере. Для корректной работы URL-параметров кейса лучше запускать через простой локальный HTTP-сервер, но сборка не нужна.

## Публикация на GitHub Pages

1. Загрузить файлы и папку `assets` в корень репозитория.
2. В GitHub открыть **Settings → Pages**.
3. Выбрать публикацию из нужной ветки и папки `/ (root)`.
4. Дождаться завершения публикации и проверить все страницы на телефоне.

Ссылки между страницами относительные, поэтому подходят для публикации в подпапке репозитория вроде `/website/`.

## Важные ограничения

- Изображения-превью проектов нарисованы CSS и явно являются декоративными обложками, а не скриншотами настоящих сайтов.
- Контактная форма не имитирует отправку заявки. Вместо неё есть GitHub и копируемый бриф.
- Перед публикацией стоит проверить содержимое реальных сайтов, заменить CSS-превью на собственные скриншоты и добавить подтверждённый Telegram username, если он нужен.
- В кейсах не придуманы отзывы, показатели, награды или бизнес-результаты.
